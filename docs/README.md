## ⚙️ System Modules Overview

FabricVision-AI integrates three specialized AI modules:

### 1. Semantic Analysis Module (`src/semantic_analysis`)
- **Engine**: Qwen2.5-VL-3B-Instruct.
- **Capabilities**: Multimodal garment analysis, fabric texture extraction, color/pattern identification, automated fashion metadata generation.

### 2. Custom Garment Generator Module (`src/custom_generator`)
- **Engine**: FLUX.1-schnell & FLUX Kontext.
- **Capabilities**: High-resolution studio garment synthesis conditioned on fabric reference textures and structured fashion metadata.

### 3. Virtual Try-On Module (`src/virtual_tryon`)
- **Engine**: CatVTON.
- **Capabilities**: Image-conditioned virtual try-on transferring synthesized garments onto target person images.
